# ⚡ Sovereign Security Architecture & Tool Directory (11 Active Projects)

Welcome to the open-source cybersecurity workbench. These frameworks are built entirely around a singular technical constraint: **100% client-side, memory-isolated, local-first execution with a zero-leakage data footprint.** By eliminating heavy SaaS backend requirements, these tools execute audits and threat simulations safely within local environments.

---

### 🧬 Operational Capability Matrix

#### 🖥️ Network Operations & Configuration Assurance
*   **[prismstrike-framework](https://github.com)** • Single-file, modular Python network operations harness for high-fidelity raw packet crafting, passive sniffing, and automated MITM lifecycle tests.
*   **[NetAST](https://github.com)** • A private-by-design compliance-as-code tool running client-side to parse complex vendor configurations into structural Abstract Syntax Trees (ASTs).
*   **[shadowbox-sec](https://github.com)** • An offline purple-team simulation workbench built to validate log-correlation pipelines against live MITRE ATT&CK techniques using synthetic telemetry.
*   **[InfraPulse-Core](https://github.com)** • High-fidelity, read-only internal network security assessment engine using a zero-mutation architecture to securely map OS-level risks.

#### 🛡️ Enterprise AI, AppSec & Cloud Posture
*   **[AegisGap-AI](https://github.com)** • Zero-trust AI security gateway enforcing real-time prompt-injection defense, structural PII masking, toxicity filtering, and model governance.
*   **[-LogicSentry-AI](https://github.com)** • Offline-first application security triage engine unifying static (SAST) and dynamic (DAST) analysis to aggressively target business-logic vulnerabilities.
*   **[CloudGarrison](https://github.com)** • A client-side, browser-native WebAssembly posture workbench mapping multi-cloud infrastructure attack paths locally without mutating cloud state.
*   **[Securiscan](https://github.com)** • Robust cybersecurity triage engine designed for passive inspection and active canary probing across APIs, Web Apps, and LLMs.

#### 🔮 Forensic Analysis, Reverse Engineering & Simulation
*   **[ipaforge](https://github.com)** • High-speed Python triage companion optimized for iOS security parsing, certificate inspection, and binary reverse-engineering.
*   **[severitas](https://github.com)** • Social-engineering awareness and simulation lab featuring isolated safe-harbor loopback environments and mandatory pre-flight authorization validation.
*   **[OmniSec-Hex](https://github.com)** • Advanced client-side cybersecurity monorepo consolidating six sovereign open-source intelligence and fuzzing workbanks.
